# 32-543. Required display; licenses; inspection sheet
Each establishment shall display the following in a conspicuous location that is readily observable by any patron:
1. The current establishment license.
2. The current license for each barber, cosmetologist, aesthetician, nail technician or hairstylist who is practicing in the establishment.
3. The current registration for each eyelash technician who is practicing in the establishment.
4. The latest inspection sheet for the establishment.
